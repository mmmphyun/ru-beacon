# Ru-Beacon 프로덕션 카피라이팅 명세서 (docs/COPYWRITING.md)

본 문서는 `web-dashboard`의 랜딩 페이지, 온보딩 위저드 3단계, Ru-Beacon 에이전트(자연어 워크플로우 생성기)에 노출될 국문 카피 전체를 정의합니다.
`humanize-korean` 원칙에 따라 AI 특유의 번역투, 상투어("혁신적인", "손쉬운", "차세대" 등), 그리고 설명용 괄호 병기를 전면 배제했습니다.

---

## 1. 랜딩 페이지 (`src/app/page.tsx`)

### 1.1 네비게이션 헤더
- **로고**: `RuBeacon`
- **버전 뱃지**: `v1.0.0`
- **링크**: `3분 연동`, `아키텍처`, `콘솔 시작하기`

### 1.2 Hero 섹션
- **상단 카테고리 뱃지**: `초저지연 마인크래프트-디스코드 브릿지`
- **메인 헤드라인**:  
  **서버 TPS 저하 없는 마인크래프트-디스코드 실시간 연동**
- **서브헤드**:  
  서버에 이벤트가 몰려도 렉이 걸리지 않습니다. 게임 속 사건을 디스코드 알림과 역할에 곧바로 반영합니다.
- **주요 버튼**:
  - `[3분 만에 시작하기]` (Primary)
  - `[아키텍처 명세 보기]` (Secondary)

### 1.3 Hero 비콘 시뮬레이터 그래픽 (`InteractiveSimulator.tsx`)
- **비주얼 콘셉트**: Ru-Beacon 고유 루비 원석 피라미드 위의 신호기(Beacon)에서 뿜어져 나오는 붉은 레이저 광선 빔 패킷 인터랙션
- **좌측 노드**:
  - 라벨: `루비 신호기 (비콘)`
  - 상태: `이벤트 대기 중`
  - 감지 대상: `다이아몬드 채굴`, `플레이어 레벨업`, `보스 처치`
- **중앙 코어**:
  - 라벨: `LMAX Disruptor 링버퍼`
  - 버퍼링 지연: `0.08ms`
  - 메인 틱 점유: `0.00ms (완전 비동기)`
- **우측 노드**:
  - 라벨: `디스코드 게이트웨이`
  - 수신 지연: `평균 45ms 도착`
  - 수신 채널: `#서버-알림`
- **인터랙션 버튼**: `[루비 신호기 이벤트 격발 테스트]`
- **격발 시 실시간 토스트**: `메인 틱 점유 0.00ms, 평균 45ms 만에 디스코드 임베드가 발송되었습니다.`

### 1.4 핵심 인프라 3대 명세 카드
- **카드 1**: `WSS 단일 계층 게이트웨이`
  - 본문: 중계 서버 없이 백엔드와 플러그인이 WebSocket으로 직접 통신하여 네트워크 홉을 최소화합니다.
- **카드 2**: `LMAX Disruptor 인메모리 링버퍼`
  - 본문: 초당 수천 건의 블록 파괴와 전투 이벤트가 폭증해도 메인 스레드 20 TPS를 방어합니다.
- **카드 3**: `디스코드 권한 실시간 동기화`
  - 본문: 별도의 웹 인증 절차 없이 인게임 플레이어와 디스코드 역할을 지연 없이 일치시킵니다.

### 1.5 빠른 3단계 연동 안내 (코드 블록 대체 요약)
- **Step 1**: `디스코드 봇 초대` — 내 서버에 전용 봇을 추가합니다.
- **Step 2**: `인스턴스 토큰 발급` — 콘솔에서 발급한 고유 토큰을 플러그인에 등록합니다.
- **Step 3**: `실시간 하트비트 확인` — 서버 부팅 즉시 핑을 감지하여 관제탑을 활성화합니다.

## 3. Ru-Beacon 에이전트 (`WorkflowWizard.tsx`)

### 3.1 상단 커맨드 바 (Command Bar)
- **상단 라벨**: `Ru-Beacon 에이전트`
- **서브 안내**: `말로 지시하면 워크플로우를 자동 완성해 주는 Ru-Beacon 에이전트`
- **입력 필드 플레이스홀더**:  
  `유저가 레벨 30에 달성하면 디스코드에 메시지를 보내줘. 박스 형태로`
- **버튼**:
  - 기본: `[자동 생성]`
  - 로딩: `[에이전트 판단 중...]`
- **성공 피드백**:  
  `자연어로부터 워크플로우 폼을 생성했습니다. 세부 조건을 검토하고 배포를 진행하십시오.`

### 3.2 환각 방어 및 유효성 검증 실패 (HTTP 400)
- **에러 모달/배너 타이틀**: `지원하지 않는 워크플로우 요구사항`
- **에러 본문**:  
  입력하신 내용 중 지원하지 않는 조건 또는 동작이 포함되어 있습니다. Ru-Beacon은 현재 아래 항목만 지원합니다.
- **지원 안내 목록**:
  - 트리거: `블록 채굴`, `플레이어 사망`, `몬스터 처치`, `레벨 달성`
  - 액션: `디스코드 임베드 전송`, `마인크래프트 명령어 실행`, `아이템 지급`

### 3.3 확신도 모호성 피드백 (0.0 < confidence < 0.7)
- **배너 타이틀**: `의도가 모호합니다`
- **배너 본문**: `지시하신 조건이 [레벨 달성] 조건과 유사합니다. 이 조건으로 적용하시겠습니까?`

### 3.4 쿼터 및 Rate Limit 초과 (HTTP 429)
- **경고 메시지**:  
  `단시간 내 요청 한도(분당 2회)를 초과했습니다. 잠시 후 다시 시도하십시오.`
- **일일 한도 초과 메시지**:  
  `무료 티어 일일 생성 한도(5회)를 모두 사용했습니다. 내일 자정에 초기화됩니다.`
