# Ru-Beacon 포트폴리오 증거 계획

## 1. 목표

Ru-Beacon은 Cloud Engineer를 목표로 한 공개 베타 프로젝트다. 보안은 필수 기반으로 포함하되, 포트폴리오의 중심은 이벤트 기반 클라우드 서비스의 설계·배포·운영·복구·확장·비용 관리로 둔다.

## 2. 부트캠프와의 차별화

SKT ALEPH 교육과정은 AI·자동화, 네트워크·Zero Trust, 접근통제, 이상탐지, SOAR 중심이다. Ru-Beacon은 이를 중복 구현하는 보안 분석 프로젝트가 아니라, 보안 요구사항을 만족하는 클라우드 운영 플랫폼으로 포지셔닝한다.

| 영역 | 부트캠프에서 보여줄 수 있는 역량 | Ru-Beacon에서 추가로 증명할 역량 |
|---|---|---|
| AI·자동화 | 탐지·보고·에이전트 자동화 | 운영 리포트·RCA 보조 자동화 |
| Zero Trust | 정책·PDP·PEP·접근통제 | 서비스·Tenant·모듈 간 인증과 격리 |
| 접근통제 | RBAC·승인·회수 | 실제 다중 관리자 플랫폼 권한 운영 |
| 이상탐지 | 로그·IOC·상관분석 | 서비스 지표·SLO·용량 데이터 운영 |
| SOAR | 탐지·조치·티켓·보고 | 장애 대응·롤백·복구·공개 베타 운영 |
| 클라우드 | 일부 인프라 기초 | IaC·CI/CD·컨테이너·Kubernetes·비용·RPO/RTO |

## 3. 역량 증거 매트릭스

| 역량 | 증거물 | 검증 방법 |
|---|---|---|
| 네트워크 | Tenant·Proxy·Backend·Ingress 구성도 | 연결·장애 실험 |
| IaC | Terraform/OpenTofu 코드와 변경 이력 | 빈 환경 재생성 |
| 컨테이너 | 이미지·레지스트리·취약점 검사 결과 | 동일 이미지 실행 |
| CI/CD | PR 검사·이미지 빌드·Staging 배포 로그 | 실패·롤백 실행 |
| 서비스 분리 | API·Bot·Worker·Plugin 책임표 | 독립 장애 주입 |
| 이벤트 시스템 | 이벤트 계약·payload·전달 보장 | 중복·유실·지연 실험 |
| 관측성 | Metrics·Logs·Traces·Alert 대시보드 | 장애 전후 비교 |
| 신뢰성 | SLO·RPO·RTO 측정표 | 복구 훈련 기록 |
| 보안 | TLS·토큰·RBAC·감사 로그 | 권한 거부·토큰 폐기 테스트 |
| 확장성 | 이벤트량·인스턴스 수별 처리량 | 부하 테스트 |
| 비용 | 서비스별 월 비용·리소스 사용량 | 최적화 전후 비교 |
| 운영 | 공개 베타 운영 리포트 | 실제 사용자·장애 데이터 |

## 4. 개발 단계별 증거

### Phase 1: 코어와 로컬 운영

- 이벤트 계약
- Docker Compose
- 단위·통합 테스트
- 계정 연동·2FA 테스트
- Worker 실행 로그
- 기본 SLO 측정

### Phase 2: Staging 클라우드

- IaC로 네트워크·서비스 재현
- CI/CD 실행 결과
- Secret·TLS 구성
- API·Bot·Worker 독립 배포
- 기본 대시보드
- 장애 주입과 복구 기록

### Phase 3: 공개 베타

- 실제 서버 운영자 온보딩
- 사용자·이벤트·워크플로우 사용량
- Discord API 429와 처리량
- 비용·리소스 변화
- 개인정보 제거된 감사 사례
- 장애 대응 타임라인

### Phase 4: 운영 개선

- 부하 증가에 따른 병목 분석
- Redis·DB·Worker 확장
- 배포·롤백 개선
- RPO/RTO 재측정
- 비용 최적화
- RCA와 후속 ADR

## 5. 필수 실험

- 2FA Monitor·Enforce

### 운영·복구

## 7. 공개 베타 운영

- 실제 서버 운영자에게 제공
- 공개 전 테스트 서버와 Staging 검증
- 운영자 온보딩 문서 제공
- 장애·점검 공지 절차 마련
- 사용자 데이터 익명화
- 토큰·IP·UUID·Discord ID 비공개
- 공개 지표는 집계값 사용
- 실제 사용 동의와 개인정보 안내 제공

## 9. AI 활용 범위

AI는 Ru-Beacon 핵심 실행 권한을 갖지 않는 운영 보조 기능으로 제한한다.

- 장애 로그 요약
- RCA 초안
- 주간 운영 리포트 생성
- 알림 우선순위 추천
- 공개 베타 데이터 요약

AI 제안은 운영자 검토 후 반영하며, 자동으로 원격 명령·권한 변경·보상 지급을 실행하지 않는다.
